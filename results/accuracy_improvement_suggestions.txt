[ 문제 진단 ]
--------------------------------------------------------------------------------

1. 심각한 클래스 불균형 (Class Imbalance)
   Train 데이터 분포:
     Floral         : 8,777개 (38.9%)
     Woody          : 7,566개 (33.5%)
     Amber_Oriental : 1,758개  (7.8%)
     Fresh          : 1,694개  (7.5%)
     Citrus         : 1,651개  (7.3%)
     Sweet          :   703개  (3.1%)
     Spicy          :   408개  (1.8%)
   
   → Floral/Woody가 전체의 72%를 차지하며, Spicy는 0.4%에 불과.
     WeightedRandomSampler를 사용하지만 Spicy F1이 0.13으로 매우 낮음.

2. 약한 CLIP 모델 (clip-vit-base-patch32)
   → 더 큰 CLIP 모델(clip-vit-large-patch14 등)을 사용하면 표현력 향상.

3. 단순한 분류 헤드 구조
   현재: LayerNorm → Linear → GELU → Dropout → Linear
   → 두 레이어짜리 MLP로 복잡한 향수 계열 분류에는 표현력 부족.

4. 임베딩 캐시 방식의 제약
   현재 cache_embeddings=True + freeze_clip=True 기본값으로
   CLIP 백본이 완전히 고정되어 있어 파인튜닝 없이 헤드만 학습.
   → CLIP 자체를 도메인에 맞게 fine-tuning하는 효과가 없음.

5. 텍스트 feature 품질 제한
   현재 build_text: "perfume name: X. brand: Y. fragrance notes: Z"
   → notes 필드가 CLIP의 77 token 한도를 초과할 경우 잘림.
     더 중요한 note 정보가 누락될 수 있음.

6. 고정된 학습률 스케줄 (CosineAnnealingLR)
   → Warmup 없이 바로 높은 lr로 시작하면 초기 불안정.

  현재: WeightedRandomSampler 사용 + label_smoothing=0.05
  문제: Spicy(51개), Sweet(87개)가 여전히 저성능

  [실험 결과] --weighted-loss 적용 시 성능 오히려 하락!
  원인: 이중 패널티(Double Penalty) 문제
    WeightedRandomSampler → 소수 클래스 이미 과샘플링
         +
    weighted CrossEntropy  → 소수 클래스에 또 높은 loss 가중치
         =
    소수 클래스에 이중 보정 → 모델 과보정 → 전체 정확도 하락

  ✅ 올바른 해결책: Focal Loss (--use-focal-loss)
     Focal Loss는 "어려운 샘플"에 자동으로 집중하는 방식으로
     Sampler와 중복 없이 작동함. 이미 코드에 추가되어 있음.

  실행 (코드 수정 불필요, 플래그만 변경):
    python data_classifier/train_clip_classifier.py ^
      --use-focal-loss ^
      --focal-gamma 2.0 ^
      --label-smoothing 0.05

  gamma 값 가이드:
    gamma=0.5 → 약한 초점 (클래스 불균형이 심하지 않을 때)
    gamma=1.0 → 중간
    gamma=2.0 → 표준 Focal Loss (기본값, 권장)
    gamma=3.0 → 강한 초점 (Spicy처럼 극소수 클래스)

  4-2. augmented train 데이터 사용 (Focal Loss와 병행 가능):
       --train-csv data/All/train_aug.csv  (이미 존재!)

  권장 실행:
    python data_classifier/train_clip_classifier.py ^
      --train-csv data/All/train_aug.csv ^
      --use-focal-loss ^
      --focal-gamma 2.0 ^
      --label-smoothing 0.05 ^
      --rebuild-embedding-cache

        name = str(row.get("name", "") or "").strip()
        brand = str(row.get("brand", "") or "").strip()
        notes = str(row.get("notes", "") or "").strip()
        
        # notes에서 핵심 노트만 추출 (앞 5개)
        key_notes = ", ".join(notes.split(",")[:5]) if notes else ""
        
        parts = []
        if name:
            parts.append(f"This is a perfume called {name}")
        if brand:
            parts.append(f"by {brand}")
        if key_notes:
            parts.append(f"with notes of {key_notes}")
        
        return ". ".join(parts) if parts else "a perfume product"
